# Auto Typer 1.1 — Windows 10/11 64비트

사용법
1. 기존 1.0 입력기가 켜져 있으면 종료한 뒤 AutoTyper.exe를 실행하세요.
2. 큰 입력칸에 자동으로 쓸 내용을 붙여넣습니다. Ctrl+V 또는 '붙여넣기' 버튼을 사용하세요.
3. 실제로 입력할 프로그램의 입력창을 클릭해 커서를 놓습니다.
4. F8을 누르면 내용을 한 글자씩 입력합니다.
5. F9 또는 다른 창으로 전환하면 중단합니다.
'3초 후 입력' 버튼을 눌렀다면 3초 안에 대상 입력창으로 전환하세요.

이번 수정
9자리 길이 검사, 영문 대문자 강제 변환, 공백 제거, 스타 실행 파일 제한을 없앴습니다.
길이가 다른 코드와 일반 문장을 입력할 수 있습니다.
실제 사용 가능한 텍스트 길이는 Windows 입력 컨트롤과 메모리에 따릅니다.
닉네임 등록 없이 큰 칸에 붙여넣고 바로 사용합니다.
입력 내용은 자동으로 파일에 저장하지 않습니다. 예전 1.0의 저장 파일은 수정하지 않습니다.

입력 방식
- 일반 텍스트: 한글, 대소문자, 숫자, 기호, 이모지를 그대로 입력합니다. 기본값입니다.
- 키보드 입력: 게임처럼 일반 텍스트 입력을 받지 않는 창에서 선택합니다.
  영문, 숫자, 공백, 기호를 미국식 키보드의 실제 키로 입력합니다.
  이 방식은 영문(US) 키배열을 기준으로 합니다. 영문 입력 상태에서 사용하세요.
  한글 등 지원하지 않는 문자가 있으면 한 글자도 입력하기 전에 안내합니다.
프로그램 종류나 실행 파일명으로 대상을 제한하지 않습니다.
대상 프로그램이 합성 입력을 받지 않거나 권한이 다르면 입력이 되지 않을 수 있습니다.

내용과 Enter
대소문자, 앞뒤 공백, 기호를 자동으로 바꾸지 않습니다.
본문의 줄바꿈은 Enter, 탭 문자는 Tab 키로 처리합니다.
따라서 대상 입력창의 동작에 따라 줄바꿈이 전송/실행으로, Tab이 다른 칸 이동으로 처리될 수 있습니다.
'끝에 Enter 추가' 기본값은 '누르지 않음'입니다. 필요할 때만 1번 또는 2번으로 바꾸세요.
사진의 게임처럼 9자리 뒤 Enter 두 번이 필요하다면 '키보드 입력'과 'Enter 2번'을 직접 선택하세요.

속도와 중단
기본 키 누름 80ms / 키 사이 대기 120ms.
키 누름 5~500ms, 사이 대기 5~1000ms로 조절할 수 있습니다.
지정 시간은 최소 대기값이며 Windows 타이머 때문에 실제 간격이 더 길어질 수 있습니다.
입력 중 다른 문자 키를 누르지 마세요. Ctrl/Alt/Windows 키 등 다른 단축키를 누르면 중단됩니다.
키보드 방식에서 Caps Lock 상태가 바뀌면 중단합니다.
중단 후 재시작은 처음부터 입력합니다. 이미 입력된 부분은 직접 확인해 비우거나 정리하세요.
이 프로그램은 대상 프로그램의 입력 결과나 로드 성공 여부를 확인하지 않습니다.

실행과 파일
파이썬이나 .NET 설치 없이 AutoTyper.exe를 실행합니다.
F8/F9을 다른 프로그램이 이미 사용하면 상태줄에서 안내합니다.
소스 코드, 빌드 스크립트와 핵심 로직 테스트도 포함했습니다.

검증 범위
Win64 실행 파일 빌드와 핵심 입력 로직 자동 검사를 통과했습니다.
1자, 9자보다 긴 문자열, 200,000 UTF-16 단위 문자열을 검사했습니다.
대소문자, 공백, 기호, 한글, 이모지, 줄바꿈, 탭, 끝 Enter 0/1/2회와 중단 처리를 검사했습니다.
이 환경에서는 Windows GUI와 실제 대상 앱에서 실행하지 못했습니다.
일반 텍스트/키보드 두 방식의 실제 앱별 키 인식은 사용 환경에서 확인이 필요합니다.
